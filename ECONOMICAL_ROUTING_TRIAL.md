# Economical agent routing trial

The bounded execution and evidence-audit trial passed. Terra completed one prescribed ear-tip edit on the existing CC0 rigged Quaternius horse; Luna correctly classified all three anonymous audit samples. Neither needed a coordinator repair or escalation.

| Responsibility | Route | Result |
| --- | --- | --- |
| Scope, controls, final verification | Astra coordinator | One candidate authorized; gate and source hashes preserved |
| Implement prescribed edit | GPT-5.6 Terra, low reasoning | Eight authorized ear-tip vertices moved by `[0, 0, 0.06]`; passed on first attempt |
| Enforce preservation | Existing Python/Blender gate | Protected geometry, materials, transforms and rig unchanged; zero changed pixels across four protected ID/matte comparisons |
| Audit anonymous evidence | GPT-5.6 Luna, low reasoning | Correctly rejected the protected-region violation and accepted both valid edits: 3/3 |

Luna reopened the saved Blender scenes to check actual vertex changes against the declared operations. The deliberate negative control moved protected vertex 25; it failed the geometry check and changed 669 head-ID pixels and 237 head-matte pixels. Both permitted samples preserved all protected comparisons. Luna's raw report has `passed: false` because it aggregates sample acceptance; rejecting the negative control is the expected, correct outcome.

There were two worker-agent dispatches, one Terra candidate capture, and three read-only Blender invocations for Luna's scene audit. The recorded driver execution times were 5.393 seconds for Terra and 5.374 seconds for Luna. These exclude agent reasoning, orchestration and setup; they are not whole-agent turnaround times. Per-agent token totals and billed credits were unavailable, so this trial does not establish a percentage or monetary saving.

This supports provisionally routing tightly specified edits to Terra and evidence audits to Luna. It does not establish anatomical judgment, visual fidelity improvement, or general reliability from three samples. The reusable mechanical audit can run as a script in later runs; premium reasoning remains useful when selecting an edit or diagnosing an unexplained failure.
