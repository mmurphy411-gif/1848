# Procedural asset pipeline

The reusable [Art Gauntlet runner](../art_gauntlet/README.md) captures and iterates
isolated deer/trout candidates, ingests blind reviews, and checks exported assets
in Blender and Godot. See the [implementation report](../ART_GAUNTLET_IMPLEMENTATION.md)
for tested behavior and current art/integration limitations.

Blender 5.2.1 LTS, bundled Python. The original procedural builders use no downloaded art;
the finished miner uses documented CC0 head anatomy and generated reference textures. Run from any
directory using `blender --background --python <absolute-script-path>`.
The scripts resolve output paths from their own locations. Seeds are explicit.

| Script | Outputs | Measured seconds, RTX 5080 |
| --- | --- | --- |
| build_textures.py | Gravel/granite 2048, other terrain 1024, shader node sources | 15 |
| build_boulders.py | Eight 1920-triangle boulders, three 160-triangle cobbles | 0.7 |
| build_bedrock.py | Two jointed 324-triangle schist ledges | 0.4 |
| build_trees.py | Four tree GLBs, four 2048 alpha atlases from Geometry Nodes | 6 |
| build_ground_cover.py | Grass, lupine, poppy and yarrow meshes | 0.4 |
| build_miner.py | Rigged miner, eight clips, body atlases, pan and poke | bake-dependent |

Each saves an inspectable `.blend` beside its script. `common.py` centralizes
Y-up glTF export, applied modifiers, normals, tangents, active vertex colors and
materials. Cameras, lights and animation are excluded. `.gdignore` excludes
these source scenes from Godot; only exported GLBs are imported, with automatic
mesh LOD enabled. Texture `.import` files explicitly enable mipmaps.

Texture coordinates embed UVs onto a four-dimensional torus: value and derivative
are periodic on both axes. Cycles bakes node-authored colors, tangent normals and
packed AO/roughness/metallic. OPTIX is used when available, CPU otherwise.
Tree atlas collections retain the Geometry Nodes instancing setups; enable one
collection at a time to inspect its spray and source leaf. The leaf textures are
shared by cards on seed-generated species-specific branch skeletons.
Blender's mathutils noise generator is seeded separately from Python's RNG.
PNG render timestamp chunks are stripped without changing pixels so foliage
atlases and their embedded GLB copies regenerate byte for byte. Godot's extracted
atlas copies in `assets/trees/` are ignored; the authored files are in `textures/`.
Regeneration verification: all 43 authored PNG/GLB outputs matched SHA-256 hashes
across repeated headless runs. All 18 terrain maps passed wrapped-edge continuity
checks; six 3×3 albedo sheets were also reviewed visually.

Run all builders, then Godot `--headless --editor --path . --import --quit`.
No gameplay, layout or lighting file is generated by Blender.

## Milestone 6 regeneration

Run `build_textures.py`, `build_trees.py`, `build_ground_cover.py`, and
`build_miner.py` with Blender. Then run `python blender/optimize_textures.py`
with Pillow installed before importing into Godot. The optimizer stores a
256-color palette in albedo/normal PNGs; dimensions and alpha are retained, with
color quantization. ORM maps are 8-bit single-channel roughness; the runtime
shaders supply the constant AO and metallic terms. `build_gravel.py` is called
by the terrain builder and uses periodic, independently placed stone populations.
`png_helpers.py` writes deterministic 8-bit PNGs without external dependencies.

The miner builder creates an inspectable high-resolution cloth-swatch collection
and bakes folds with Cycles selected-to-active tangent normals. Four swatches
occupy atlas quadrants. The 1024 body atlases use the milestone's performance
fallback. The separate 512 pan map adds irregular scuff marks. Geometry supplies
the pan's crease, cuff silhouette, hat, beard and five-finger hands. The source
is `build_miner.blend`; its NLA tracks are muted for inspection of the rest pose.
Unmute one track to preview an individual clip. `build_miner_animation.py`,
imported by the builder, solves two-bone hand/foot IK and bakes at 30 fps. It
authors `pan_socket` under RightHand, including the transfer to left-hand carry.

Tree and miner GLBs export material placeholders to avoid embedded atlas copies.
Runtime materials bind shared external maps. Miner surface order is deliberate:
Linen, Wool, Leather, Skin, Felt, Beard, Suspenders, Buckle, Ivory. The miner exporter includes
skin weights and NLA animation; the static-asset export policy above applies only
to the other builders. Pan and sack retain their exported materials. All binary
sources and outputs are tracked through Git LFS.

## Milestone 6 notes regeneration

No suitable CC0 humanoid base mesh was available offline, so this round uses the
permitted procedural sculpt pass. No external base mesh or third-party art was
introduced. `build_miner.py` adds fuller sleeves, cuff and belt gathers, a broader
brim, a shaped beard with separate 512-pixel strand albedo/normal maps, smooth
skin, three-segment separated fingers, a connected thumb web and a tied poke.
The body atlas remains 1024 pixels. Palm width follows the finger row in the
rest mesh; the thumb web blends between the hand and thumb bones.

`build_miner_animation.py` now exports ten tracks: the original eight plus two
distinct swirl variants. The hips remain 0.52 m above the soles during swirl,
torso/head pitches are 43/63 degrees, and the three pan radii are
0.102/0.110/0.118 m. The pan hangs by its rim beside the leg when carried.

`build_trees.py` retains the full species and builds three distant conifers at
416 triangles each, sharing the original atlases. The oak's first two limb
orders are tubes; its bark uses an opaque runtime shader and its interior leaf
cards use the alpha-to-coverage foliage shader. `build_gravel.py` emits an
additional exact stone-population mask for render validation.

Regenerate with the same Blender commands above, then import in Godot. The
notes review harness is `tests/miner_notes_capture.gd`; `--stills-only` and
`--sequences-only` select its two capture jobs. Run
`python tests/probe_miner_notes.py` for still-image gates and
`python tests/build_pan_review.py` for contact sheets and animated previews.

## Miner art pass

The playable character now uses the finished anatomical miner described in
[MINER_GAME_INTEGRATION.md](../MINER_GAME_INTEGRATION.md). Its editable art source
is `miner_finished.blend`, built by `finish_miner.py` from the retained refinement;
`miner_game_export.blend` is the reduced, baked game derivative.
Run `export_intrepid_miner.py -- prepare`, then `-- bake`,
then `-- export` with Blender in background mode. The output is
`assets/miner/intrepid/miner.glb`, eight modular skinned meshes with baked atlases.
The original builders below remain the legacy geometry and activity-clip pipeline;
running `build_miner.py` does not update the playable convergence character.

`miner_detail.py` adds facial anatomy, eyelids, a shaped beard, clothing details
and boot soles to the existing rig. `build_pack.py` exports the separate canvas
knapsack and saves `build_pack.blend`. Run it before the Godot import, and run
`build_mining_animation.py` after `build_miner.py` for the curled mining grips
and updated rocker hand targets. The original panning joints and paths remain
compatible. See [MINER_ART_REVIEW.md](../MINER_ART_REVIEW.md) for captures,
measured budgets, contact checks and remaining art limitations.

## Wildlife

Reference convergence sources for the supplied buck and rainbow trout are
`deer_convergence_working.blend` and `trout_convergence_working.blend`. Both have
passed the subjective silhouette/proportion gate and received initial polish.
See [ANIMAL_CONVERGENCE_REVIEW.md](../ANIMAL_CONVERGENCE_REVIEW.md) for checkpoints,
comparisons, reproduction commands, geometric verification and remaining likeness
limits. These high-detail art sources are independent of the live game exports.

The later from-scratch gauntlet study is separate:
`deer_gauntlet_blank.blend` is its empty baseline and
`deer_from_scratch_working.blend` is the retained blind-reviewed checkpoint.
See [DEER_FROM_SCRATCH_REVIEW.md](../DEER_FROM_SCRATCH_REVIEW.md) for the actual
gate outcome. Rebuild through `gauntlet_recipes/deer.py` and the versioned plans
in `art_gauntlet/plans/`; this study does not replace either the earlier source
or the runtime deer.

Run `blender --background --python blender/build_wildlife.py` to regenerate
bear, deer, squirrel, quail and jay GLBs in `assets/wildlife/`, plus the matching
`build_bear.blend`, `build_deer.blend`, `build_squirrel.blend`,
`build_quail.blend` and `build_jay.blend` sources. Models use meters, with Blender
+Y facing forward (Godot -Z). Preserve the named Head, Tail, limb, lower-limb
and wing pivots: `wildlife_actor.gd` uses them for animation and foot placement.

The generator joins static details into moving parts, supplies white vertex
colors where no tint is authored, and retains subtle surface-normal guard
hairs. Wildlife materials are shared at runtime. See
[WILDLIFE_REVIEW.md](../WILDLIFE_REVIEW.md) for measured geometry budgets and
candid limitations of this first animal pass.
